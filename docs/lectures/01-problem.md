# 1. 문제 정의 — 강의 학습 (Minb "강의" 메뉴)

2026-11-13 그릴링 인터뷰로 확정. 이 문서와 02~04가 이 기능의 기억이다.

## 누가, 어디서
- **사용자**: 나 혼자(Google 로그인 계정). 남에게 보여 주지 않는다.
- **기기**: 주로 PC와 아이패드. 휴대폰은 읽을 수만 있으면 된다.
- **취급 난이도**: 나만 씀 × 원격(웹) → 로그인과 내 계정 전용 권한만 확실하면 된다.

## 병목
- 유튜브 강의(양실장의 바이브코딩대학 "뿌리 강의")를 `lecture-study-pack` 스킬로 PDF 3종(교육자료·시험지·정답)으로 만들어 공부 중이다(1~7강).
- PDF는 같은 28문항만 반복되어 두 번째부터는 답을 외워서 풀게 된다. 채점도 손으로 해야 하고 점수 기록이 남지 않는다.

## 해결할 것 (P0)
1. Minb 하단 메뉴에 **강의** 탭. 강좌(바이브코딩 뿌리 강의) → 강의(1~7강) → [교육자료] [시험] 3단계.
2. 교육자료를 웹에서 읽기. 장 목차로 이동. "인쇄 / PDF로 저장" 버튼.
3. 강의마다 **문제은행 100문항**(객관식 80 + 주관식 20). "새 시험지 뽑기"마다 객관식 20 + 주관식 8을 장별로 고르게, 안 본 문제부터 뽑는다. 보기 순서도 섞는다.
4. **정답 보기** → 객관식 자동 채점(문항당 2점, 40점). 주관식은 모범답안과 채점표가 열리고, 채점 항목을 체크하면 합산 → 60점 만점으로 환산.
5. 새로고침해도 풀던 시험지·답은 그대로.
6. 응시 기록(날짜·점수·틀린 문항) 저장, 오답마다 "복습: N장" 링크. 강의 목록에 최근 점수·응시 횟수.
7. 교육자료 셀프 체크 체크 상태 저장, 목록에 "셀프 체크 5/8".

## 수동·자동 경계
- 강의 자료와 문제은행은 사용자가 "웹에 올려줘"라고 할 때만 Claude가 올린다(자동 업로드 X — 관련 없는 강의가 섞이지 않게).
- 주관식 채점은 사용자가 채점표를 보고 직접 체크한다.

## 성공 기준
- PC·아이패드에서 강의 하나를 읽고, 새 시험지를 뽑아 풀고, 채점까지 끝낼 수 있다.
- 같은 강의를 다섯 번 봐도 처음 네 번은 겹치지 않는 문제가 나온다(객관식 80 ÷ 20).

## 미룬 것
- P1: AI 주관식 채점, 틀린 문제만 다시 풀기, 틀린 문제 가중 출제.
- P2: 장별 "읽음" 표시, 홈 대시보드 "강의" 카드.
